# Sangue Universitário – protótipo

Site estático (HTML/CSS/JS). Abra `index.html` ou publique a pasta inteira.

## Publicar
**Vercel:** suba a pasta no GitHub → vercel.com → Add New Project → importe o repositório → Deploy
(Framework: Other, sem build command, sem output directory). O `vercel.json` aplica os headers de segurança.

**GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. (O `vercel.json` é ignorado lá.)

## Atenção
- Nomes de arquivos são case-sensitive no servidor: mantenha tudo em minúsculas como está.
- Login, cadastro e formulários são simulados: nada é enviado ou salvo.
- As regras da pré-triagem devem ser validadas por profissional do HEMOAM antes de uso real.
